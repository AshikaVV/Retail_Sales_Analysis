Retail Sales Analysis

Project Overview

This is a beginner-friendly Python project that analyzes retail sales data and generates a summary report.

Objectives

- Calculate revenue for each product.
- Calculate total and average revenue.
- Identify the highest and lowest revenue products.
- Visualize product revenue using a bar chart.
- Export the sales report as a CSV file.

Tools Used

- Python
- Matplotlib
- CSV

Key Skills

- Basic Python programming
- Data calculations and analysis
- Data visualization
- Report generation

How to Run

1. Install Python.
2. Install Matplotlib using "pip install matplotlib".
3. Run "Retail Sales Analysis.py".
